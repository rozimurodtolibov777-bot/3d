# STRIKEPOINT 3D FPS — GitHub Pages uchun statik versiya

Bu variant Vite build talab qilmaydi. Three.js brauzerda jsDelivr CDN orqali yuklanadi; internet aloqasi kerak.

## GitHub'ga joylash
1. ZIP'ni oching.
2. Ichidagi `index.html`, `src/`, `README.md` va `package.json` fayllarini GitHub repozitoriy `3` ning asosiy (root) qismiga yuklang. ZIP'ni o'zini emas, ichidagi fayllarni yuklang.
3. `Settings → Pages → Build and deployment` bo'limida **Deploy from a branch** ni tanlang.
4. Branch: `main` (yoki fayllaringiz turgan branch), folder: `/(root)`, keyin Save.
5. Bir-ikki daqiqa kutib, `https://rozimurodtolibov777-bot.github.io/3/` sahifasini Ctrl+F5 bilan yangilang.

Agar Pages'da **GitHub Actions** tanlangan bo'lsa, uni `Deploy from a branch` ga almashtiring. Bu statik variantga build workflow kerak emas.
